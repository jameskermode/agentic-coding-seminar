# CECAM abstract (replacement, to send to the organisers)

**Event:** Mary Ann Mansigh Series, "Who writes the code? Algorithms, software, creativity, and reliability in the age of AI", CECAM/EPFL (online), 27 October 2026, 16:50 slot.

**Title:** Effective Agentic Coding for Scientific Computing

**Subtitle:** The code is the easy part: asking the questions, checking the answers, and training who does both

Agentic coding tools now write most of the code in some of our projects: in ace-jax, a JAX implementation of the atomic cluster expansion, almost all code was agent generated. The code was the easy part. The human work was deciding what "correct" means: parity tests against independent codes, benchmarks, and certification. Even then, a bug slipped past automated tests because they asked the wrong questions. A Terminal-Bench-Science task I wrote tells the same story: once a problem is fully specified, the newest models solve it. The skills that make agentic AI safe (knowing when to interrupt, what to validate against, and which question to ask) came from years of struggle. I will argue that research training must deliberately protect them, and describe the HetSys Centre for Doctoral Training AI policy and mini-viva assessment as part of the response.
