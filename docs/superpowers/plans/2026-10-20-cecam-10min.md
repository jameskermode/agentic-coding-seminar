# CECAM 10-minute Variant Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `"cecam"` version of the deck: 9 slides, 10 minutes, plus a committed handout. The three delivered decks must stay byte-for-byte unchanged in their rendered output.

**Architecture:** In `agentic-coding-seminar-shared.typ`, directly after the helper definitions inside `#deck` (helpers end at `#let phase(...)`, ~line 161), wrap everything that follows in one branch: `#if version == "cecam" [ …CECAM slides… ] else [ …existing slides, untouched… ]`. Typst markup ignores indentation, so the existing slides are not re-indented. The only change to them is one closing `]` added before the final `] // end of #let deck`. Two new one-line shims call `#deck("cecam")`. `github_claude_stats.py` gains a `--fig-suffix` option, so the re-run writes dated figure copies instead of overwriting the old ones.

**Tech Stack:** Typst 0.14.2; Python via `uv run`; `gh` CLI.

**Spec:** `docs/superpowers/specs/2026-10-20-cecam-10min-design.md` (all slide content, verified facts and quotes live there. Read it before Task 3).

## Global Constraints

- Title: "Effective Agentic Coding\nfor Scientific Computing". Subtitle: "The code is the easy part: asking the questions, checking the answers, and training who does both".
- Author line: "James Kermode · School of Engineering, University of Warwick". Date line: "27 October 2026 · CECAM Mary Ann Mansigh Lecture (online)".
- Maximum 9 logical slides (handout pages). Reveals are allowed, but the live deck stays ≤ 18 pages.
- Only verbatim text goes in quotation marks. Kresse verbatim: "The end of human programming?" and "At the VASP Software GmbH, about 70% of our team now uses multi-agent LLM pools to develop software." Anything else attributed to him is paraphrase, without quotation marks.
- Use the model name "GPT-6 Astra" (as in PR #1646 and the system cards).
- Reuse the shared vocabulary only: `slide`, `phased-slide`, `phase`, `titleslide`, `twocol`, `bullet`, `note`, `warn-block`, `good-block`, `bad-block`, `codebox`, and the palette (`accent`, `accent2`, `light`, `warn`, `green`, `red-bg`).
- The research, Brookes and MPIP decks and handouts render identically to their pre-change output (Task 1 golden hashes).
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Slide overflow.** `slide` is a fixed-size `page`, so overflowing content spills onto an extra page. The handout page count must equal exactly 9; a 10th page means a slide overflowed. Pinned in Tasks 3 and 4.
2. **The delivered decks drift.** Any edit outside the `cecam` branch changes the old decks. Pinned by the golden-hash check, re-run in every task.
3. **The cecam deck silently uses the old figures.** It must reference `figures/*-2026-10.png`, never `figures/heatmap.png` or `figures/transition.png`. Pinned by a grep in Task 4.
4. **Misquotes.** Quotation marks around non-verbatim Kresse text, or misreported benchmark numbers. Pinned by a grep in Task 3 against the spec's verbatim strings.
5. **The script with no suffix.** It must keep writing `heatmap.png`/`transition.png` exactly as before. Pinned in Task 2.
